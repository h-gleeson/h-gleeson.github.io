This folder is a template for new experiments.
1. Copy this entire folder into `experiments/` and rename it to your experiment's slug.
2. Place gallery images in the `images` subfolder, named `{slug}_1.png`, `{slug}_2.png`, etc.
3. Update `index.html`: title, header title, sidebar info blocks, and description. List each image with its own `<img>` tag (with `alt` text) inside `.gallery-content`.
4. Add a card for it in the "Experiments" section of the homepage `index.html`.
